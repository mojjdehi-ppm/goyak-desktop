09 · Uses the reserve buses AYNA’s route tenders already require per carrier; no new standby fleet

Carriers already keep reserve buses per route; AYNA’s tenders require them. We do not propose a new standby fleet. When Ritm sees a large gap starting to form, the advisor ranks the options: which reserve vehicle, from which terminal, where it should join. It weighs the empty drive against the passenger-minutes it saves. The dispatcher sees the reasons and picks one, or keeps the bus in reserve. This module has been validated in simulation only, and we say so.
